# Security Policy

## Reporting a Vulnerability

Private vulnerability reporting is not enabled for this repository, so no private reporting channel is currently available. Do not include details of an unpatched vulnerability in a public issue or discussion.

The repository owner can enable private reporting in [Security settings](https://github.com/hayes-ulricu4b97qv/tyoechonext/settings/security_analysis). After it is enabled, use the repository's [Report a vulnerability](https://github.com/hayes-ulricu4b97qv/tyoechonext/security/advisories/new) form.
