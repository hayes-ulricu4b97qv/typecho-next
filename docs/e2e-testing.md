# Windows 端到端测试

## 执行

需要 Windows、PowerShell、Go、MinGW-w64 GCC、Node.js 22 及 Microsoft Edge。测试使用 Playwright 启动无头 Edge，不需要安装额外的浏览器。

在项目根目录执行：

```powershell
cd web
npm ci
npm run test:e2e
```

浏览器安装在非默认位置时，设置 `$env:E2E_BROWSER_PATH = 'C:\path\to\msedge.exe'`。

脚本自动构建 Vue 前端和 Windows 服务程序，选择空闲端口，使用 `%TEMP%\typecho-e2e-*` 目录保存本次运行的数据。服务在运行结束后停止，并清理本次创建的临时数据目录；实际博客的数据库和上传目录不参与测试。

结果输出到 `.e2e-artifacts/report.json`，包括各流程的结果、耗时、失败堆栈和浏览器异常。该目录还包含服务日志、成功截图或失败时的管理页面截图；它会被下一轮测试更新，不提交到 Git。

可设置 `E2E_ARTIFACTS_DIR` 将本次结果写入其他目录，以保留现有诊断文件。

## 覆盖范围

- 首次设置、就绪检查、浏览器登录。
- 移动端管理台分区导航，以及 390px 和 320px 视口下的页面横向溢出检查。
- 设置分区导航、修改和保存状态、离开提醒、未登录入口和移动端设置布局；锚点滚动完成后检查标题避开粘性页头与分区导航。
- 文章发布、Markdown 渲染、危险 HTML 清理、草稿隐私和授权预览。
- 修改文章并保留固定链接、修订恢复。
- 独立页面创建、修改、公开读取和删除。
- 分类重命名、关联保留、页面导航与分类筛选的分批加载和跨页链接可达。
- 正文搜索、搜索字符数边界、公开分页、订阅和站点地图对草稿及未来文章的过滤。
- 读者端浏览器前进/后退恢复分页，迟到的旧搜索结果不能覆盖最新结果。
- 分页数据总数缩小时重读最后一页；读者端的修正页请求失败时不会提前更改 URL。
- 读者搜索框和提交按钮可通过键盘到达，输入框保留可见焦点轮廓。
- 图片上传；在文章和页面光标位置插入 Markdown 图片；检查预览中的图片说明，并确认页面预览与公开阅读渲染一致；拒绝伪装图片。
- 阅读口令、错误提示和正确口令重试。
- 匿名评论、审核、线程回复、关闭评论。
- 拒绝包含 userinfo 的评论作者网址，并将历史响应中的欺骗网址显示为普通作者名称。
- 首屏或后续评论分页读取失败后可重试；追加失败保留已显示楼层，重试仍使用相同页码和游标。
- CSRF 校验、编辑与审核角色权限、停用用户后的会话失效。
- 超过 100 篇文章的管理分页、审计分页。
- 管理端筛选读取失败时保留已显示的筛选状态；登出期间完成的旧身份响应不能恢复管理会话。
- 站内通知分页仅在响应成功后更新页码，加载中的按钮不可重复触发。
- 所有者改密后的当前会话保留及其他会话撤销。
- 备份下载、媒体缺失时失败、服务重启后持久化。
- ZIP 恢复到空目录后的文章、评论、会话和图片验证。
- 浏览器删除文章、媒体、标签和工作人员，验证对应资源失效。
- 移动端阅读布局和浏览器运行异常。

部分边界数据通过真实服务的 API 生成，再通过浏览器或 HTTP 验证，未使用模拟后端。测试不连接外部邮件服务，也不证明邮件实际投递。

Windows CI 会运行此命令并上传 `.e2e-artifacts/`，失败时可下载报告和截图。
